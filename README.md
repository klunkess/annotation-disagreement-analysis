# Annotation Disagreement Analysis

## Overview

This project investigates disagreement patterns in human evaluations of conversational AI safety using SQL.

Using Google's DICES-350 dataset, I aim to identify which conversations produce the most disagreement between evaluators, explore differences across safety categories, and investigate potential sources of inconsistent judgments.

## Dataset

**Source:** [Google Research — DICES](https://github.com/google-research-datasets/dices-dataset)

- 350 AI conversations
- 123 human evaluators
- 43,050 evaluation records

## Research Questions

1. Which conversations have the highest evaluator disagreement?
2. Do certain safety categories produce more disagreement than others?
3. How do human judgments compare with expert reference labels?
4. What patterns might help improve evaluation quality?
